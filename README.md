# Editor e Conversor de PDF - SEMED

Aplicação web moderna, completa e intuitiva para visualização, edição e conversão de arquivos PDF e documentos diretamente no navegador.

## 🚀 Funcionalidades

### 📄 Editor de PDF (`index.html`)
- **Editar Texto**: Clique sobre qualquer texto do PDF para editar diretamente com quebra automática de linha nos limites da página.
- **Novo Texto**: Adicione novas caixas de texto com controle de fonte, tamanho, cor, negrito, itálico e sublinhado.
- **Apagar Área / Tarja**: Cubra ou remova trechos do documento facilmente.
- **Desfazer / Refazer**: Suporte completo a atalhos de teclado (`Ctrl+Z` / `Ctrl+Y`) e botões no cabeçalho.
- **Gerenciamento de Páginas**: Mover para cima, mover para baixo, girar 90° e excluir páginas de forma independente.
- **Adicionar Novos Documentos**: Insira outros arquivos PDF em qualquer posição do documento atual.

### 🔄 Conversor de Documentos (`converter.html`)
- **PDF para Word (.docx)**: Transforma PDFs em arquivos editáveis do Microsoft Word preservando texto e parágrafos.
- **Word (.docx) para PDF**: Converte arquivos `.docx` em documentos PDF formatados.
- **Imagens (JPG/PNG/WEBP) para PDF**: Combina uma ou várias fotos em um único arquivo PDF com ajuste de orientação (Retrato, Paisagem ou Auto).
- **PDF para Imagens**: Renderiza cada página do PDF em alta resolução (JPG ou PNG) e permite download avulso ou em pacote `.zip`.
- **PDF para Excel (.xlsx)**: Extrai linhas e tabelas do PDF diretamente para planilhas do Microsoft Excel com abas por página.
- **Juntar múltiplos PDFs**: Mescla vários arquivos PDF em um único documento sequencial.
- **Dividir PDF**: Extrai páginas avulsas ou intervalos específicos (ex: `1, 3-5`) para um novo arquivo PDF.
- **PDF para Texto (.txt)**: Extração limpa e estruturada de todo o conteúdo textual.

## 🔒 100% no Navegador (Privacidade & LGPD)
Todo o processamento ocorre localmente no dispositivo do usuário utilizando Web APIs e bibliotecas client-side (`PDF.js`, `PDF-lib`, `Docx.js`, `SheetJS`). Nenhum dado ou documento é enviado para servidores externos.
