# Editor de PDF - SEMED

Aplicação web moderna e intuitiva para visualização e edição de arquivos PDF diretamente no navegador.

## 🚀 Funcionalidades

- **Editar Texto**: Clique sobre qualquer texto do PDF para editar diretamente.
- **Novo Texto**: Adicione novas caixas de texto com controle de fonte, tamanho e cor.
- **Apagar Área / Tarja**: Cubra ou remova trechos do documento facilmente.
- **Formatação de Texto**: Suporte a Negrito, Itálico, Sublinhado e alinhamento.
- **100% no Navegador**: Processamento local, seguro e rápido sem envio de dados para servidores externos.
